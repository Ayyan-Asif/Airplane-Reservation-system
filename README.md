# ✈️ Airline Reservation System

A console-based Airline Reservation System developed in **C++** that demonstrates the practical implementation of **Object-Oriented Programming (OOP)** and **Data Structures & Algorithms (DSA)** concepts.

The system allows users to manage flights, book and cancel seats, view passengers, manage seat allocation, display flight routes, and maintain data using file handling.

---

## 📌 Features

- View all available flights
- Search flights by origin and destination
- Book airline seats
- Cancel bookings
- Automatic waitlist management
- View passenger list
- Display seat availability
- Add new flights
- Display flight route map
- Persistent data storage using file handling
